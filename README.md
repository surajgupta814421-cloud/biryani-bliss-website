
# Biryani Bliss — Indian Restaurant Website

A responsive restaurant website concept inspired by
Indian biryani and the royal Nawabi dining tradition.

## Features

- Biryani-focused food menu
- Indian dishes, starters, breads and desserts
- Search and category filters
- Food photographs and sample pricing
- Shopping cart and quantity controls
- Google Maps location and directions
- Configurable restaurant contact details
- Optional WhatsApp enquiry
- Optional link to the restaurant's Zomato listing
- Responsive desktop and mobile design

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

1. Open the folder in VS Code.
2. Open index.html with Live Server.
3. Browse the menu and test the cart.

## Important

This is a frontend portfolio demonstration.
Menu items, prices, photographs, contact details,
location and opening hours must be verified before
using the site for a real restaurant.

The website does not process payments or send orders
directly to Zomato.
